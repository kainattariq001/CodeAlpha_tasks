# CodeAlpha_Calculator

A modern, responsive, and feature-rich scientific calculator built using HTML, CSS, and JavaScript.

This calculator supports both basic and advanced scientific operations with a clean user interface and smooth functionality.

---

## Features

### Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

### Scientific Functions
- Sin (sin)
- Cos (cos)
- Tan (tan)
- Logarithm (log)
- Square Root (√)

### Extra Features
- Dark Mode 🌙
- Keyboard Input Support ⌨️
- Calculation History 📜
- Responsive Design 📱
- Interactive User Interface ✨

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## How to Use

1. Clone the repository
2. Open `index.html`
3. Start calculating

This portfolio showcases professional skills, academic background, completed projects, and includes a working contact form.

---

## Features

### Core Sections
- **Home:** An eye-catching landing section with a professional introduction.
- **About Me:** Details about my academic background and journey.
- **Skills:** A dedicated section highlighting my technical expertise.
- **Projects:** Showcase of all internship tasks (including the Scientific Calculator).

- **Formspree Integration:** A fully functional contact form that sends messages straight to my email. 📬
- **Smooth Scrolling:** Easy and fluid navigation between different sections.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports. 📱
- **Interactive UI:** Smooth animations, clean typography, and modern hover effects. ✨
